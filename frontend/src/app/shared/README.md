# shared/

Composants réutilisés par plusieurs modules : boutons, badges de
statut, tableaux, états vides, modales.

**Règle :** aucun composant de ce dossier ne contient de logique
métier. Un `<app-status-badge>` sait afficher un statut, il ne sait
pas ce qu'est un lavage.

Ce dossier sera rempli au **Lot 2** (design system).
